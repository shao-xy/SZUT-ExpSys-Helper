# 实验系统基本流程

本文件描述在站点上人工完成一次实验排课的全过程，是 `labreg` 工具实现的依据。
工具已覆盖第 4~8 步；第 1~3 步属于教师职责，**必须由教师手工完成**。

| 步骤 | 内容 | 责任方 |
| --- | --- | --- |
| 1 | 检测站点连通性 | 工具自动；不通时提示使用学校 VPN |
| 2 | 登录站点 | 工具自动（验证码自动识别） |
| 3 | **安排课程大纲、提交实验任务书** | **教师手工，工具不代劳** |
| 4 | 进入「制订课表（整班排课）」，逐行「进入制定」 | 工具自动 |
| 5 | 确认学生 → 学生分批 → 制定课表 | 工具自动 |
| 6 | 确认学生（点「引用」导入学生） | 工具自动 |
| 7 | 学生分组（全选，批数填 1，确认分批） | 工具自动 |
| 8 | 制定课表（周次、周几、节次、批次、地点） | 工具自动 |

---

1. 主站点首页为：[首页 | 实验教学管理系统](http://10.28.203.178/index2.aspx)。由于位于校园网内，因此首先应检测连通性。如果不连通，应提示使用者使用学校VPN。
2. 访问主站点（[首页 | 实验教学管理系统](http://10.28.203.178/index2.aspx)），登录密码由用户提供（不要使用统一认证登录）
3. 左侧“实验教学管理”中的“制订课表（整班排课）”。如果此页面没有任何内容，终止本次任务，并提示用户先提交任务书再重新运行。
   > **教师职责**：在提交任务书之前，还需先在系统中安排并提交本门课程的课程大纲。
   > 这两步都属于教学管理决策，必须由教师本人在系统中手工完成，
   > 工具与 Agent 均不得代填、代写、代提交。
4. 对于每一行，都需要点击“进入制定”来安排实验课程。同一门课程可能因为不同班级而导致有多行，都需要分别制定。
5. 制定每门实验课程分为“确认学生”、“学生分批”和“制定课表”三步。可在点击进入制定的界面分别点击“进入确认”、“进入分批”和“制定课表”进行操作。
6. 确认学生时，下方会有“完全匹配到的课程信息”，点击某个班级的“引用”按钮即会自动导入所有学生，页面自动刷新，上方会显示已经确认的学生人数和名单。页面上方有红色字“下一步：点击进入学生分组”，点击可直接进入学生分批（分组）。
7. 学生分组时，首先需要点击“进入分批”。在绝大多数情况下（除非用户主动要求对学生人工分组），否则整个班都是一组，表示实验是同时发下去的。页面下方会显示所有学生（上一步确认的学生）。点击全选后，“输入分批数”处填“1”，表示分1批，点击“确认分批”.系统提示“成功分批”。上方出现红色“下一步：进入制定课表”字，点击后可直接进入制定课表界面。
8. 制定课表时，选中班级后，点击上方“批量制定排课”可进入排课界面。对于每个实验，都需要由用户指定周次（第几周到第几周）周几、第几节到第几节，学生批次（选择第1批，因为只有1批），上课地点。上课地点有很多，但是要先选别名才能选机房编号，这一点比较坑。比如我101教室是“算法设计实验室”（其实都是公共机房，只是名字不同）。全部填好后提交，就完成了一个课程一个班级一个实验的安排。有多个课程、班级和实验时，需要依次操作进行。并且每个课程的时间可能完全不同。

## 工具补充的两条站点细节

以下两条在人工操作中不易察觉，但直接决定工具能否正确排课：

1. **周次是「每周」还是「单/双周」由排课表单上的一个下拉框决定。**
   下拉框有三个选项：「请选择」（即每周）、「单周」、「双周」。
   选「单周」或「双周」会导致隔周上课。

   工具支持这三种排法，由计划文件中的 `parity` 字段控制：
   留空或写 `每周` 表示每周上课，写 `单周` / `双周` 表示隔周上课。
   该字段可写在班级上作为默认值，也可由单个实验覆盖。

2. **一次排课提交会按周次拆成多条记录。**
   例如第 1-3 周排课，站点上会生成第 1、2、3 周共 3 条记录，
   每条对应一周的实际日期。这是正常结果，不代表重复排课。
   单双周排课同理，只生成对应奇偶的周次：
   第 1-8 周选「单周」会生成第 1、3、5、7 周共 4 条记录。

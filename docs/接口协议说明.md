# 实验系统接口协议

本文件记录实验教学管理系统（实验教学管理系统 / 实训教学管理系统）的实际接口与表单字段，
供后续维护脚本时查阅。全部内容由浏览器 HAR 抓包 + 实际登录抓取页面逆向得到，并已在真实站点验证。

## 一、站点概况

| 项目 | 内容 |
| --- | --- |
| 站点地址 | `http://10.28.203.178/`（校园网内，不在内网需先连 VPN） |
| 技术形态 | ASP.NET WebForms，全部交互为 HTML 表单回发，无 JSON API |
| 登录页 | `index2.aspx` |
| 公共参数 | 登录后 URL 携带 `sid`、`screen`、`roles`，后续所有请求都必须带上 |

### 公共参数

```
sid=3D3DD538033B1BB2
screen=A9B1B716F321939D
roles=F7832E1476455FE8
```

`roles` 仅在从菜单进入时出现，任务页可不带。

### 隐藏域

每次表单回发都必须携带当前页面抓到的隐藏域：

- `__VIEWSTATE`
- `__VIEWSTATEGENERATOR`
- `__EVENTVALIDATION`（部分页面存在，缺失时必须删除旧值，否则回发校验失败）

页面抓取后应立即提取并覆盖缓存，不能复用其他页面的值。

## 二、登录

### 验证码

```
GET GenerateIdentifyingCode.aspx?t=<毫秒时间戳>
```

返回 PNG 图片，需与登录请求使用同一 Session。脚本用 `ddddocr` 识别。

### 登录提交

```
POST index2.aspx
Content-Type: application/x-www-form-urlencoded

UserId=<账号>
Password=<AES 加密后的密码>
IdentifyingCode=<验证码>
btnLogin=登录
__VIEWSTATE=...
__VIEWSTATEGENERATOR=...
__EVENTVALIDATION=...
```

密码加密方式（与前端 `JsAESEncrypt` 一致）：

- 算法：AES-CBC
- key 与 iv 相同，均为 `Easyman-easyman3`
- 填充：PKCS7
- 输出：Base64

```python
key = iv = b"Easyman-easyman3"
cipher = AES.new(key, AES.MODE_CBC, iv)
ciphertext = cipher.encrypt(pad(password.encode("utf-8"), 16, style="pkcs7"))
encoded = base64.b64encode(ciphertext).decode()
```

成功响应为 `302`，`Location` 指向 `Main/Menu.aspx?sid=...&screen=...&roles=...`。

**注意**：部分站点实例启用了统一身份认证，此时需改走另一套入口；本项目使用账号密码登录。

## 三、排课三步流程

以 (班级, 实验项目) 为单位，共三步。页面之间的跳转关系：

```
kbjxlist2.aspx   课程列表（一个教学班一行）
   └─ kbxjlist.aspx   班级任务表（一个实验项目一行，共 5 行）
        ├─ jskclist.aspx    第一步 确认学生
        ├─ jsfzlist.aspx    第二步 学生分批（跳转到 xsteam.aspx 操作）
        └─ fzKeBiao.aspx    第三步 制定课表
             └─ plkb2.aspx   批量排课表单
```

### 页面地址与公共查询串

任务页与排课页都需要：

```
coursecode=00000000          课程代码
kxh=示例课程-0001A      课序号（班级），中文需 URL 编码
rwid=72732                   任务号
xmid=37514                   实验项目号
sid=...&screen=...
```

> `kxh` 只编码一次。若先用 `quote()` 编码再交给 `urlencode()`，会出现双重编码，页面返回空表。

### 表格结构

**kbjxlist2.aspx**（`table#gvUser`，3 列）

| 列 | 内容 |
| --- | --- |
| 课程名称[代码] | 如 `示例课程[00000000]` |
| 课序号 | 如 `示例课程-0001A` |
| 制定课表 | 「进入制定」链接，指向 `kbjxlist.aspx` |

**kbjxlist.aspx**（`table#gvUser`，9 列）

| 列 | 内容 |
| --- | --- |
| 编号 | 1~5 |
| 课程名称[代码] | 课程代码取方括号内 |
| 课序号 | 班级名 |
| 项目名称[代码] | 实验项目名，取 `xmid` |
| 选课学生 | 如 `47人` |
| 确认学生 | 「进入确认」→ `jskclist.aspx` |
| 学生分批 | 「进入分批」→ `jsfzlist.aspx` |
| 已制定数 | 已排课条数 |
| 制定课表 | → `fzKeBiao.aspx` |

## 四、第一步：确认学生

页面 `jskclist.aspx`：

- `span#qrxscount` —— 已确认学生人数
- `table#gridview` —— 「完全匹配到的课程信息」表格
  - 第 2 列是匹配人数（如 `47`）
  - 「引用」按钮：`input[value='引用']`，name 形如 `gridview$ctl02$ctl00`
  - 「批量引用」按钮：`input[value='批量引用']`，name 为 `Button6`

提交引用：

```
POST jskclist.aspx?<查询串>
Content-Type: multipart/form-data

__EVENTTARGET=
__EVENTARGUMENT=
__LASTFOCUS=
gridview$ctl02$ctl00=引用
FileUpload1=(空文件)
```

表单 `enctype` 为 `multipart/form-data`（页面含文件上传控件），**必须带 `files` 参数**，
否则 `requests` 会以 urlencoded 提交，服务端无法正确解析。

> **陷阱**：回发响应中的 `qrxscount` 仍是提交前的值，必须重新 GET 一次页面确认结果。

## 五、第二步：学生分批

`jsfzlist.aspx` 为入口页，实际操作在 `xsteam.aspx`。

页面元素：

| 元素 | 说明 |
| --- | --- |
| `span#lblwqr` | 未分批学生人数 |
| `input#CheckBox1` | 「全选」复选框 |
| `input[name^='skxyid$']` | 每个待分批学生一个复选框 |
| `input#fzs` | 分批数输入框 |
| `input#Button_FZ` | 「确认分批」按钮 |
| `select#ddlbj` | 行政班筛选，`0` 表示全部 |
| `table#DataList_fxqk` | 已分批情况表，含「删除该批」等按钮 |

提交分批（整班一批）：

```
POST xsteam.aspx?<查询串>
Content-Type: application/x-www-form-urlencoded

ddlbj=0
fzs=1
Button_FZ=确认分批
CheckBox1=on
skxyid$0=on
skxyid$1=on
...（所有待分批学生）
__VIEWSTATE=...
```

分批成功后，`cblxs` 学生批次下拉中会出现 `(第1批)`，其 `span` 的 `alt` 属性为批次 ID
（如 `138638`），后续排课需带上该批次。

> 同样地，回发响应可能是提交前状态，需重新 GET 确认。

## 六、第三步：制定课表

`fzKeBiao.aspx` 上有「批量制定排课」按钮（`input#Button4`），提交后 `302` 跳转到 `plkb2.aspx`。

### plkb2.aspx 表单字段

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `ddlxm` | select | 实验项目，对应 `xmid`，共 5 项 |
| `ddlzc1` | select | 起始周次（1~24） |
| `ddlzc2` | select | 结束周次（1~24） |
| `ddldsz` | select | 单双周，选项：`''`(请选择) / `单周` / `双周` |
| `cblweek$N` | checkbox 组 | 星期几，`span[alt]` 为 1~7（1=周一 … 7=周日） |
| `ddljctype` | select | 节次类型，固定 `标准时间节次` |
| `ddljie1` | select | 起始节次（1~12） |
| `ddljie2` | select | 结束节次（1~12） |
| `cbz1` / `cbz2` / `cbw1` | checkbox | 中午一节 / 中午二节 / 晚上一节 |
| `tbshi` / `tbfen` | text | 开始时间 时 / 分 |
| `tbshi2` / `tbfen2` | text | 结束时间 时 / 分 |
| `cblxs$N` | checkbox 组 | 学生批次，`span[alt]` 为批次 ID |
| `ddllab` | select | **实验室别名**（先选这个） |
| `ddlfj` | select | **具体机房编号**（由别名级联产生） |
| `hidtype` | hidden | 固定 `2` |
| `hiduid` | hidden | 教师 ID，用于冲突检查 |
| `hidkcdm` | hidden | 课程代码 |
| `btnSubmit` | submit | 「提 交」 |

### 关键：单双周

`ddldsz` 三选一：

| 取值 | 含义 |
| --- | --- |
| `''` | **每周**（不区分单双周） |
| `单周` | 只排奇数周 |
| `双周` | 只排偶数周 |

该值随表单一起提交即可生效，无需单独为它触发回发：
提交后重新抓取该页，`ddldsz` 的 `<option>` 会带上 `selected="selected"`。

「单周/双周」按**绝对周次的奇偶**判定，与 `ddlzc1` 的起始周无关。
例如 `ddlzc1=9, ddlzc2=15` + `单周`，产生第 9、11、13、15 周共 4 条记录。

计划文件中的对应字段是 `parity`：`每周`/`""` → 留空，`单周` → `单周`，`双周` → `双周`。

### 关键：地点的两级级联

地点必须先选实验室别名（`ddllab`），机房编号（`ddlfj`）才会被级联填充。

别名与机房的对应关系因学校而异，**不需要事先知道**：工具会遍历页面上的全部别名，
逐个触发一次回发，读出该别名下的机房列表，建立「房号 → (别名 ID, 机房 ID)」映射。
配置里只需写房号。

| 别名 ID | 别名 | 机房 ID | 机房文本格式 |
| --- | --- | --- | --- |
| （站点给出） | 实验室别名一 | （站点给出） | `N0000[校区-楼栋-房号]` |
| （站点给出） | 实验室别名二 | （站点给出） | `N0000[校区-楼栋-房号]` |

机房文本形如 `N0000[校区-楼栋-房号]`，**方括号前为房号**，即配置中 `room` 应填的部分。
查本机的对应关系可运行 `scripts/probe_rooms.py`。

### 关键：提交顺序（必须逐步回发）

站点通过回发事件联动填充数据，因此提交顺序不能颠倒：

1. `__EVENTTARGET=ddllab` —— 选别名，响应中 `ddlfj` 才会有机房选项
2. `__EVENTTARGET=ddljie1` —— 选起始节次
3. `__EVENTTARGET=ddljie2` —— 选结束节次，**响应中回填 `tbshi`/`tbfen`/`tbshi2`/`tbfen2`**
4. 提交 `btnSubmit=提 交`

第 3 步响应里的起止时间需要读出来，放进第 4 步的表单一起提交。

### 节次与时间对照（标准时间节次）

| 节次 | 起止时间 |
| --- | --- |
| 1-2 | 08:00 - 09:35 |
| 3-4 | 09:50 - 11:25 |
| 6-7 | 13:30 - 15:05 |

### 冲突检查

提交前页面会调用三个异步接口，参数中的 `weeks` 是星期序号（如 `4,` 表示星期四）：

```
GET admin/ashx/checkjs.ashx?kbid=&jsid=<教师ID>&zc1=&zc2=&jie1=&jie2=&weeks=&coursecode=
GET admin/ashx/checkxs.ashx?kbid=&xsteams=<批次ID,>&zc1=&zc2=&jie1=&jie2=&weeks=&coursecode=
GET admin/ashx/checkfj.ashx?kbid=&fjid=<机房ID>&zc1=&zc2=&jie1=&jie2=&weeks=&coursecode=
```

返回空串表示无冲突，非空为冲突说明。浏览器遇到冲突会弹「是否强制排课？」确认框。

### 排课结果

站点**每周生成一条记录**。例如第 1-3 周排课会产生第 1、2、3 周共 3 条记录。

结果表格中每行包含：上课班级、上课教师、上课时间、上课地点、详情、操作。

- 上课时间格式：`2026-09-24 09:50 - 11:25 第3周 [星期四] 3 -4节`
- 上课地点格式：房号，如 `N0000`
- 「删除」链接：`a[id^='Repeater1_ctl'][id$='lbdel']`，通过 `__doPostBack` 触发

**删除注意**：删除后列表重新编号，控件 id 会变化（`Repeater1_ctl01_lbdel` → 原 `ctl02` 变成 `ctl01`）。
所以删除后必须重新抓取页面再取下一个控件 id，不能沿用旧列表。
